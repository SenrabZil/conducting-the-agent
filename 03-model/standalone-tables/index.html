Lesson 06 of 7 · Standalone tables

Some tables stand alone on purpose.

Four tables have no relationships at all. In most models that's a bug. Here, each one is a choice.

with Elizabeth Cecilia. About 8 minutes.

1

Four tables, no lines

In Model view, four tables have no relationships at all. In most models that's a mistake. Here each one is deliberate, because none of them describes rows in a fact table.

_MeasuresThe home for every measure. No data to relate.
DimMeasureBasisThe register. It describes measures, not trade or prices.
FactReleaseGateThe checklist of release checks shown on the assurance page.
MigrationCandidatesThe table-by-table plan shown on the migration page.

Sort by a hidden order

Text sorts A to Z. Stages of a process don't. So two text columns are sorted by a number column next to them: FactFacilities[State] by StateOrder, and a pipeline Stage column by StageOrder. You set it in Table view with Column tools > Sort by column.
