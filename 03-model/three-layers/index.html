Three passes, one direction

The data starts in one Excel workbook. Power Query reads it in three groups of queries, and each group reads only from the one before it. The names come from the lakehouse "medallion" pattern, which is useful later: if the model moves to Microsoft Fabric, each group becomes a set of lakehouse tables and the model on top barely changes.

BBronze

The sheet, exactly as it arrived. No fixes.

Group: Bronze — raw

SSilver

Cleaned: types set, spaces trimmed, names made consistent. One cleaning query per table.

Group: Silver — cleansed

GGold

Shaped for the model: facts and dimensions, keys, sort-order columns.

Group: Gold — model

Pick a layer for each job.

Read the workbook sheet exactly as it is
Set column types and trim stray spaces
Remove duplicate rows
Rename columns to one naming convention
