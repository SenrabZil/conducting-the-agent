Triage

Fix the file, fix the spec, or carry on?

A FAIL means the files and the disagree. Usually the file is wrong, but not always.

WARN optional page not built

FAIL visual.json is not valid JSON
Check

Fix forward or roll back?

One FAIL, in one small file, and you can see exactly why.

After regenerating every page: 140 FAILs across files you didn't expect to change.

Recap

Three things to keep

  • 1A good FAIL line names the file, the thing and the rule. You shouldn't have to search.
  • 2Read FAILs top-down and look for the : fix the first cause, not every symptom.
  • 3A FAIL means file and spec disagree. Usually fix the file; sometimes the spec is what's out of date.
