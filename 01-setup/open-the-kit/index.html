Lesson 06 of 7 · Open the kit

Open the kit. Look around. Don't save.

Time to open the report. The first click is easy. The habit that matters is how you close it.

with Elizabeth Cecilia. About 8 minutes.

1

Three files, three jobs

The kit comes in three forms. Two are downloads from the latest release on the kit's GitHub page: open Releases, then Assets. The third, the project, comes with your clone. Pick by what you want to do:

📄 The PDF: sample.pdf, a printout of every page. Download it from the release. Good for a first read on a phone.

📊 The .pbix: sample.pbix, the whole report in one file. Download it from the release, then double-click to open it in Desktop and click around. This is the one most lessons expect.

🗂️ The .pbip project: the same report saved as folders of plain text. That's what Git tracks and what Claude Code edits. Open it by double-clicking the .pbip file.

You've just opened the .pbix. What do you need to do before the pages show data?

2

If a refresh can't find its workbook

Refresh reads the source workbook again. Its location is stored once, in a parameter called WorkbookPath. On your PC that path will point at a folder that doesn't exist, until you change it.

Answer the question above to unlock this.
⚠️ Refresh failed: could not find the file at C:\Users\builder\Documents\kit\source.xlsx

Where do you fix it?

Type the path to the workbook in your copy of the kit, for example C:\conducting-the-agent-kit\source.xlsx, then select OK.

A simulation.

3

Look, don't save

Clicking around changes things: slicer selections, which page is open, sometimes a visual you nudged by accident. When you're done exploring, close Desktop and choose Don't save. Your copy stays exactly as it arrived, and the lessons keep matching it.

Want to experiment? Use File > Save as first and give it a new name, like practice.pbix. Break that one freely.
